## Overview
Single-user web app for managing Gmail via the Gmail API. Google OAuth for authentication, JWT in HttpOnly cookies.

## Architecture
- **Backend:** FastAPI + SQLAlchemy + PostgreSQL + Alembic + PyJWT + httpx (`backend/`)
- **Frontend:** React 18 + TypeScript + Tailwind CSS 4 + Vite + React Router v6 (`frontend/`)
- **Deploy:** Docker Compose (api + frontend + postgres), Nginx reverse proxy
- **Ports:** API=8003, Frontend=3003

## Development Commands

All dependencies run inside Docker containers only (never install on host).

```bash
# Start dev environment (with hot reload)
make dev-build              # or: docker-compose -f docker-compose.dev.yml up -d --build

# View logs
make dev-logs

# Shell into API container
make dev-shell

# Run all tests
docker compose run --rm api pytest tests/

# Run a single test
docker compose run --rm api pytest tests/test_auth_and_poller_regressions.py::test_function_name

# Frontend lint & typecheck
docker compose -f docker-compose.dev.yml exec frontend npm run lint
docker compose -f docker-compose.dev.yml exec frontend npm run typecheck
```

### Database Migrations
```bash
make migrate                                    # Apply pending migrations
make migrate-create MSG='description'           # Create new autogenerated migration
make migrate-rollback                           # Undo last migration
make migrate-history                            # Show migration history
make migrate-stamp                              # Mark DB as current (skip applying)
```

## Backend Structure
```
backend/app/
├── main.py          # App init, lifespan (starts poller), logging config
├── config.py        # Pydantic BaseSettings from .env
├── db.py            # SQLAlchemy engine & session
├── models.py        # All DB models (User, Label, Rule, CleanupJob, SystemLabelRetention, AuditLog)
├── deps.py          # FastAPI dependency: require_jwt_user (JWT cookie → User)
├── routers/         # auth, labels, rules, cleanup, settings
└── services/        # gmail_service (httpx), google_service (OAuth), jwt_service, rule_engine, poller, ai_service
```

**Key service patterns:**
- `GmailService` wraps Gmail REST API via httpx — no google-api-python-client
- `RuleEngine.build_rule_query()` constructs Gmail search queries from rule criteria; excludes action label to prevent loops
- `Poller` runs as a daemon thread, uses Gmail History API for delta updates, applies rules + retention cleanup
- `GoogleService.ensure_fresh_token()` auto-refreshes OAuth tokens before API calls

## Schema Changes & Migrations
Whenever you modify `backend/app/models.py` (add/remove/alter columns, tables, or constraints), you **must** immediately generate a corresponding Alembic migration:
1. Run `make migrate-create MSG='short_description_of_change'` — this autogenerates a migration inside Docker that correctly chains off the latest revision.
2. Review the generated file in `backend/alembic/versions/` to verify the `upgrade()` and `downgrade()` operations match your intent.
3. Run `make migrate` to apply the migration to the dev database.

Do **not** hand-write migration files or manually set `Revises:` — always use `make migrate-create` so Alembic resolves the revision chain automatically.

## Key Patterns
- **Auth flow:** Google OAuth → callback → exchange code → issue JWT → HttpOnly cookie (`gmail_auth`)
- **Single-user mode:** `GOOGLE_ALLOWED_EMAIL` env var restricts access to one Google account
- **Per-request auth:** `require_jwt_user` dependency validates JWT, fetches User from DB
- **Pagination:** All Gmail API calls paginate with `max_results` + `page_token`; batch APIs used for bulk operations
- **DB models:** User has 1:N relationships to Rule, Label, CleanupJob, SystemLabelRetention, AuditLog
- **Logging:** Named loggers per module (`auth`, `labels`, `rules`, `cleanup`, `gmail`, `poller`, `ai`); level via `LOG_LEVEL` env var
- **Testing:** In-memory SQLite, monkeypatch external services (httpx, Gmail API responses)

## Environment Variables
See `.env.example` for all required variables. Key ones:
- `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` — Google Cloud Console OAuth credentials
- `GOOGLE_ALLOWED_EMAIL` — restricts which Google account can log in
- `APP_SECRET_KEY` — for signing JWT tokens
